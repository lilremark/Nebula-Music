This beta is a design pass across the whole app, plus new ways to make Nebula
your own: themes, fonts, animated backgrounds and a sidebar you can fold up.

## Features

- Add themes in Settings under Appearance: Nebula, Midnight, Graphite, Rose, Forest, Nord, and the text-mode Terminal, Amber and ASCII Mono.
- Add a choice of interface fonts, including Inter, DM Sans, Space Grotesk, Plus Jakarta Sans, Source Serif and JetBrains Mono.
  - Fonts other than the default are downloaded from Google Fonts the first time you pick them.
- Add animated backgrounds: Aurora, Dot Grid, Grid, Flickering Grid, Particles, ASCII Field and ASCII Rain.
  - Backgrounds pause while the window is hidden and stay still when your system asks for reduced motion.
- Collapse the Discover, Library and Playlists groups in the sidebar. The playlist list now scrolls to show all your playlists, with a button to create a new one.
- Refresh the layout of every screen: consistent page margins and titles, a page title that appears in the top bar as you scroll, and matching headers for albums, playlists and artists.
- Redesign Settings with clearer controls and a wider layout.
- The About section on album pages now uses the full width of the page.
- Deleting a playlist now asks for confirmation in place instead of in a separate dialog.
- Add an Exit Demo Mode button in Settings.

## Bug fixes

- Fix the sidebar needing to scroll in short windows.
- Fix track times shifting width as they count up.

## Notes

The full-screen player keeps its own colours under every theme for now; it
follows the chosen font only. Some screens may still show default greys under
the coloured themes. Reports are welcome.
