## AI DJ Settings refinement

AI DJ preferences now use the same switches, dropdowns, buttons, typography and
row spacing as the other Settings sections. Model downloads and requirements
sit in a padded section, and voice level includes a percentage readout.
The layout adapts to compact windows and light/dark themes.

Local AI DJ still starts from Discover. Models remain an optional 2.01 GB
download in Settings, and previously downloaded models remain available after
updating. Windows x64 and 16 GB RAM are recommended; CPU inference requires
no dedicated GPU. Allow 5 GB free disk space for initial model installation
(7 GB for repair).

See [AI DJ behavior and requirements](https://github.com/lilremark/Nebula-Music/blob/beta/docs/ai-dj.md).
