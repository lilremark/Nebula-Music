title: Faster, Lighter Desktop App
---

This beta focuses on making Nebula lighter on your computer: less background
CPU, smaller downloads, and less work while the app sits in the tray. Features
and settings are unchanged.

## Performance

- Nebula does almost no work while hidden in the tray. Animations, the visualizer and progress updates pause, and playback keeps going.
  - In the tray, renderer and graphics CPU drop from about 1–2% to 0% in our tests.
  - Crossfades, gapless playback and live radio are unaffected.
- Progress bars update with playback instead of redrawing every frame, and the visualizer and mini-player animations stop when playback is paused.
- Changing playback state now re-renders only the parts of the app that use it, instead of the whole interface.
- The mini-player window is closed instead of hidden when you dismiss it, so it frees its memory.
- On Windows, the AI DJ's local model and voice processes shut down after two minutes without use and restart when needed.
- Smaller desktop downloads: the Windows app is about half its previous installed size, and the macOS app no longer includes Windows-only AI DJ components.
- Faster startup from a main process about a quarter of its previous size.
- Network requests for audio and artwork no longer pass through an extra check in the app's main process.

## Bug fixes

- Fix animations and visual effects continuing to run while the window was hidden in the tray or minimized.

## Notes

The web player and Docker image include the rendering improvements. The tray,
process and download-size changes apply to the Windows and macOS apps. Docker
beta images are now published as `lilremark/nebula-music:beta`.
