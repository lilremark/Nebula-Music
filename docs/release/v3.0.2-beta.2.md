---

This beta lets you choose to send anonymous crash reports from the desktop app,
so problems on real machines can be found and fixed faster. Reporting is off
until you turn it on.

## Features

- Add optional, anonymous crash reports on Windows and macOS. A one-time banner asks whether to share them, and you can change your choice anytime in Settings under Crash Reports.
  - Reports include the error, the app version, your operating system and a random install ID that is deleted when you turn reporting off.
  - Your server address, credentials, library, listening history and file paths are never sent, and reports are not linked to your IP address. See [docs/privacy.md](https://github.com/lilremark/Nebula-Music/blob/beta/docs/privacy.md).
  - Nothing is sent, and the reporting code is not loaded, until you choose Share.

## Notes

Crash reporting applies only to the Windows and macOS apps; the web player and
Docker image are unchanged.
