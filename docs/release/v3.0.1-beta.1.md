# Nebula 3.0.1-beta.1

This beta includes all updates on the beta branch since Nebula 3.0, for Windows
x64 and macOS Apple Silicon.

## ReplayGain

Settings → Sound now offers Off, Track and Album normalization, a -12 to +12 dB
preamp, and peak-based clipping protection. ReplayGain is off by default and uses
tags supplied by your music server. It does not scan or modify your music files.

Track mode balances individual songs; Album mode preserves volume differences
within an album. Each side of a crossfade receives its own gain adjustment.
Volume, EQ, internet radio, and DJ speech retain their existing controls.

## Playback and server feedback

- Loading and buffering indicators follow the active track, including prepared
  crossfade handoffs.
- Playback errors stay visible with retry or skip guidance.
- A connection warning appears when the music server becomes unreachable, with
  a retry action and automatic recovery checks.

## Web and Docker

- Fix startup and playback on plain-HTTP LAN or VPN addresses by removing the
  secure-context requirement from generated client IDs.
- Keep desktop settings in the desktop app and local AI DJ on Windows.
- Include the Docker 3.0 setup and documentation updates already on beta.

## Dependency updates

All 41 direct dependencies were verified against their current stable npm tags.
Updates include Electron 45.1.0, React 19.3.1, Motion 14.7.1, ONNX Runtime 1.31.1,
Vite 8.3.5, Vitest 5.0.5, and vgpu 0.6.0. The orb renderer is adapted to the
updated shader format. The dependency audit reports zero known vulnerabilities.
Linux verification skips optional CUDA downloads while retaining the bundled
CPU runtimes.

The full test suite, coverage gates, typechecking, production builds, native
startup, platform settings, DJ UI/shaders, native inference, and ReplayGain audio
checks passed locally. The release workflow verifies both platform builds and
their update metadata before publishing.
