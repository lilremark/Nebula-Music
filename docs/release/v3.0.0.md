## Nebula 3.0

This stable release integrates the beta line into main with the redesigned
library, responsive players, refined search, expanded Quick Picks, paginated
rotation, and refreshed native mini player. Playback recovery, account-scoped
caches, desktop IPC hardening, secure redirects and persistence fixes are included.

All direct npm dependencies were checked against the registry's latest stable
versions on October 9, 2026. Updated dependencies and an ONNX installer proxy
override remove the known advisory chain; the complete npm audit reports zero
known vulnerabilities. This is a dependency scan and focused code review, not
a guarantee that every application vulnerability has been eliminated.

Optional local AI DJ is exclusive to Windows x64. Web and macOS hide its
navigation and settings, expose no DJ capability, and cannot start inference
or download models. Windows users must explicitly download models and start a
session; it remains an experimental feature.

Windows x64: use `Nebula-3.0.0-setup.exe`, or the unsigned AppX package.
macOS Apple Silicon: use `Nebula-3.0.0-arm64.dmg` or the ZIP bundle.
Both builds are unsigned; macOS is not notarized. Windows updates install
automatically; macOS updates link to the release for manual installation.

README screenshots were captured with Computer Use from the real 3.0 app in
an isolated Demo Mode profile. No personal music server or installed account
was used.
