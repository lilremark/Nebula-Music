## Local AI DJ

AI DJ is now a dedicated view under Discover. Start a session there; it greets
once and introduces the next set after **4 or 5 completed tracks**. Skips shape
your recommendations without counting as completed tracks. Familiar, Balanced
and Discover adjust the mix; Balanced aims for roughly 60% familiar and 40%
less-played related music, adapting to your available library.

Choose speech between sets or over lowered music, Michael or Heart, and optional
transcription in **Settings → AI DJ**. Listening habits and inference stay on
your device. The DJ uses verified track metadata and short, grounded phrases;
it does not generate artist trivia. Stop leaves the curated queue playing, and
Return to previous queue restores the queue you had before starting.

During speech, players show a purple audio-reactive orb and speech progress.
Normal Next skips the interlude. Players retain the music queue and standard
controls; session management lives in Discover. A static cover is used when
reduced motion is enabled or WebGPU is unavailable. The sidebar and bottom player
keep a subtle purple gradient while DJ is active.

### Download models before starting

The models are **excluded from the installer**. In **Settings → AI DJ**, select
**Download DJ models**. Nebula downloads SmolLM3-3B Q4_K_M and Kokoro-82M quantized
English voices/phonemizer from pinned upstream Hugging Face sources, verifies
every file, and enables AI DJ only when ready. The download is **2.01 GB**
(1.87 GiB). Progress, cancel, retry and repair controls are available. Models
persist in the app's data folder across app updates. No API key, Ollama, Python
or external model service is required; after download, inference works offline.
Music still needs access to your Subsonic server.

| Requirement | AI DJ beta |
| --- | --- |
| Platform | Windows x64 desktop; browser/macOS cannot start local DJ |
| Memory | 16 GB RAM recommended; slower CPUs may skip late interludes |
| Processor | CPU inference supported; no dedicated GPU required |
| Disk | Allow 5 GB free for initial model installation, 7 GB for repair |
| Network | One explicit 2.01 GB model download, plus access to your music server |

Inference has been checked on a 32 GB Ryzen 7 9800X3D.
The 16 GB reference-machine test, long real-server listening, sleep/resume and
an installer upgrade remain manual acceptance items for this beta.
